# Atiya's Kitchen

Atiya's Kitchen is a fully responsive fine dining restaurant website built 
with pure HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies, 
no build tools required.

The website represents Lahore's premier Pakistani fine dining experience, 
where authentic traditional cuisine meets modern elegance. It includes five 
fully functional pages — Home, Menu, Gallery, Reservation, and Contact — each 
crafted with smooth animations, scroll reveal effects, and a warm dark aesthetic 
inspired by ember and spice tones.

Key features include an animated hero section with floating particles, a 
filterable menu showcasing authentic Pakistani dishes with PKR pricing, an 
interactive photo gallery with a lightbox viewer, and a reservation system 
where guests can pre-order their food items before arriving. The site also 
includes a custom SVG favicon, a parallax quote section, animated counters, 
a scrolling ticker, and a fully responsive layout that works across all 
screen sizes.

Built as a single HTML file, the project is lightweight, fast, and extremely 
easy to deploy. It is currently live on Vercel and version controlled via GitHub.
